4. Google AdMob 광고

앱은 메인 화면 하단에 Google AdMob 배너 광고를 표시합니다. AdMob SDK는 다음 정보를 수집·처리할 수 있습니다.

  • 광고 ID(Android 광고 ID): 광고 게재와 맞춤 광고, 광고 성과 측정
  • 앱 상호작용: 광고 노출·클릭 등 광고 관련 활동, 부정 클릭 방지
  • 진단·충돌 정보: 광고 SDK의 안정적 동작과 오류 분석
  • IP 주소, 기기 모델·운영체제 등 기기 정보

이 정보는 Google이 수집하며 Google 개인정보처리방침과 Google 파트너 사이트·앱 데이터 사용 방식이 적용됩니다. 개발자는 AdMob이 수집한 개별 정보를 받지 않고, 집계된 광고 보고서만 확인할 수 있습니다.

광고 ID 재설정·삭제 방법 (Android)

  • 설정 > 개인정보 보호(또는 Google) > 광고 > 광고 ID 재설정 또는 광고 ID 삭제
  • 메뉴 이름은 기기 제조사와 Android 버전에 따라 조금씩 다를 수 있습니다.
  • Google 내 광고 센터에서 맞춤 광고를 끌 수도 있습니다.

광고 동의 (Google 사용자 메시지 플랫폼)

  • 앱은 Google의 사용자 메시지 플랫폼(UMP)으로 이용자의 지역에 광고 동의가 필요한지 확인합니다. 유럽경제지역(EEA)·영국 등 동의가 필요한 지역에서는 앱 시작 시 동의 메시지가 표시되며, 이용자는 광고 개인 최적화와 데이터 사용에 동의하거나 거부할 수 있습니다.
  • 동의 여부가 결정되기 전에는 광고를 요청하지 않습니다. 동의를 거부해도 앱의 모든 기능을 이용할 수 있으며, 이 경우 개인 최적화되지 않은 광고가 표시될 수 있습니다.
  • 동의가 필요한 지역에서는 설정 화면의 광고 개인정보 옵션에서 언제든 동의를 변경하거나 철회할 수 있습니다.
  • 동의 상태는 기기에 저장되며, 동의 확인 과정에서 Google이 기기 정보를 처리할 수 있습니다.

5. 권한 사용

  • 위치(대략적 위치): 현재 위치의 날씨를 보여주기 위해 사용합니다. 앱은 대략적 위치 권한(ACCESS_COARSE_LOCATION)만 요청하며, 정밀 위치 권한(ACCESS_FINE_LOCATION)은 요청하지 않습니다. 날씨는 시·구 단위로 충분하기 때문입니다. 거부해도 설정에서 지역을 직접 선택해 이용할 수 있습니다. 앱이 열려 있을 때 날씨를 불러오는 시점에만 위치를 읽습니다.
  • 알림, 정확한 알람, 잠금 화면 전체 화면 표시, 재부팅 후 알람 복원: 이용자가 정한 시각의 매일 날씨 알람과, 앱이 날씨를 불러올 때 비·눈·강풍·미세먼지·폭염·한파 조건에 해당하면 띄우는 기상 알림에 사용합니다. 알림은 기기 안에서 예약·생성되며 외부 푸시 서버를 쓰지 않습니다. 알람과 각 기상 알림은 설정에서 끌 수 있습니다.
  • 인터넷: 날씨 조회, AI 요청, 광고, 외부 링크 열기에 사용합니다.

6. 음성 안내(TTS)

날씨 안내 음성은 기기에 설치된 음성 합성(TTS) 엔진으로 재생합니다. 앱은 안내 문장을 기기의 TTS 엔진에 전달할 뿐 음성 파일을 만들어 외부로 보내지 않으며, 마이크를 사용하지 않습니다. 음성 안내를 이용자가 켜 둔 경우 하루 첫 실행 때(오전 7시~오후 9시) 자동 재생되며, 상단 스피커 버튼으로 끌 수 있습니다.

7. 제휴 링크, 외부 사이트, 다른 앱 소개

  • 제휴 링크 고지: 한국 지역의 날씨를 볼 때 준비물 추천에 표시되는 상품 링크에는 쿠팡파트너스와 네이버 커넥트(네이버쇼핑) 제휴 링크가 포함되어 있습니다. 이 링크를 통해 상품을 구매하면 개발자가 해당 플랫폼으로부터 일정액의 수수료를 받을 수 있으며, 이용자가 내는 가격에는 영향이 없습니다. 이때 메인 화면 하단에도 같은 내용을 안내합니다.
  • 이동 전 확인: 상품 링크를 누르면 실제로 이동할 주소와 "제휴 링크이며 수수료를 받을 수 있습니다"라는 안내가 담긴 확인 화면이 먼저 나타나며, "이동"을 눌렀을 때에만 연결됩니다.
  • Amazon Associates: 현재는 사용하지 않습니다. 도입하는 경우 이 방침과 앱 안에서 안내합니다.
  • 외부 사이트: 쇼핑몰, Google Play 등 앱 밖으로 이동한 뒤에는 해당 사이트·앱의 개인정보처리방침이 적용되며, 방문 사실은 그때 해당 플랫폼에 전달됩니다.
  • 다른 앱 소개: 설정 화면의 "K-Brain Games Lab의 다른 앱"은 버튼을 눌렀을 때 Google Play의 해당 앱 페이지로만 연결됩니다. 이 과정에서 Wedi의 정보나 기기 정보를 다른 앱과 공유하지 않습니다.

8. 보관 기간과 삭제 방법

  • 기기 안 정보(메모, 설정, 지역·즐겨찾기, API 키, 날씨 캐시): 이용자가 삭제하거나 앱을 삭제할 때까지 기기에 보관됩니다.

    • Claude API 키: 설정에서 입력란을 비우기
    • 날씨 캐시: 설정 > 데이터 관리 > 날씨 캐시 초기화
    • 전체: Android 설정 > 애플리케이션 > Wedi > 저장공간 > 데이터 삭제, 또는 앱 삭제
  • Android 백업: 메모와 설정은 Android 자동 백업 기능에 따라 이용자의 Google 계정 백업이나 새 기기 이전에 포함될 수 있습니다. 이 백업은 개발자가 접근할 수 없으며 기기 설정에서 끌 수 있습니다. Claude API 키는 백업과 기기 이전에서 제외됩니다.
  • 개발자 서버: 운영하지 않으므로 개발자가 보관하는 정보가 없습니다.
  • 외부 서비스·광고: 3항·4항의 서비스가 받은 정보는 각 서비스의 정책에 따라 보관·삭제됩니다. 광고 ID는 4항의 방법으로 재설정·삭제할 수 있습니다.
  • 자세한 방법은 데이터 삭제 안내에 있습니다.

  • Location (approximate): used to show weather for where you are. If voice briefing is on, it plays automatically on the first launch of the day (7 a.m.–9 p.m.), and you can turn it off with the speaker button at the top.
