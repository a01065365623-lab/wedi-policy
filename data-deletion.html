Wedi 데이터 삭제 안내 / Data Deletion

앱 / App: Wedi (com.wedi.app) · 개발자 / Developer: K-Brain Games Lab · 시행일 / Effective date: 2026-11-10
한국어 · English

Wedi는 회원가입이 없고 개발자 서버를 운영하지 않습니다. 메모·설정·지역 등 앱의 모든 데이터는 이용자 기기에만 저장되므로, 이용자가 기기에서 직접 삭제할 수 있으며 별도 승인 절차나 대기 시간이 없습니다.

1. 앱 안에서 삭제하기

  1. 메모: 메인 화면의 메모 목록에서 각 메모의 휴지통 버튼을 누르면 즉시 삭제됩니다.
  2. Claude API 키: 설정 화면의 Claude AI 추천 입력란을 비우면 기기에서 지워집니다.
  3. 날씨 캐시: 설정 > 데이터 관리 > 날씨 캐시 초기화를 누르면 저장된 날씨 값과 마지막 음성 재생 날짜가 삭제됩니다.
  4. 즐겨찾기 지역: 설정의 지역 목록에서 삭제할 수 있습니다.

2. 전체 데이터 한 번에 삭제하기

  • Android 설정 > 애플리케이션 > Wedi > 저장공간 > 데이터 삭제: 메모, 설정, 지역·즐겨찾기, API 키, 날씨 캐시가 모두 삭제됩니다.
  • 앱 삭제(제거): 기기에 저장된 모든 데이터가 함께 삭제됩니다.

3. 개발자 쪽에 남는 데이터

개발자는 서버를 운영하지 않으며 이용자 데이터를 받거나 보관하지 않으므로, 대신 삭제해 드려야 할 데이터가 없습니다. 날씨 조회(기상청, OpenWeatherMap, Tomorrow.io), 지역명 조회(Nominatim), AI 요청(Anthropic, 이용자가 API 키를 입력한 경우)으로 전송된 정보는 각 서비스의 정책에 따라 처리됩니다.

4. 광고 데이터

Google AdMob이 수집하는 광고 ID 등은 Google 정책에 따라 관리됩니다. Android 설정 > 개인정보 보호(또는 Google) > 광고에서 광고 ID를 재설정·삭제할 수 있고, Google 내 광고 센터에서 맞춤 광고를 끌 수 있습니다.

Wedi has no account and the developer does not operate a server. All App data, such as memos, preferences, and locations, is stored only on your device, so you can delete it yourself at any time, with no approval process or waiting period.

1. Deleting Data in the App

  1. Memos: tap the trash button on a memo in the main screen's memo list to delete it immediately.
  2. Claude API key: clear the Claude AI field in Settings to remove it from the device.
  3. Weather cache: Settings > Data Management > Reset Weather Cache deletes stored weather values and the date of the last voice briefing.
  4. Favorite locations: remove them from the location list in Settings.

2. Deleting Everything at Once

  • Android Settings > Apps > Wedi > Storage > Clear data: deletes memos, preferences, locations and favorites, the API key, and the weather cache.
  • Uninstalling the App: deletes all data stored on the device.

3. Data Held by the Developer

The developer does not operate a server and does not receive or store your data, so there is nothing for us to delete on your behalf. Information sent for weather (KMA, OpenWeatherMap, Tomorrow.io), place names (Nominatim), and AI requests (Anthropic, only if you entered an API key) is handled under each service's own policy.

4. Advertising Data

Advertising identifiers collected by Google AdMob are managed under Google's policies. You can reset or delete your advertising ID in Android Settings > Privacy (or Google) > Ads, and turn off personalized ads in Google My Ad Center.
